# Book Search Feature - PRD & Technical Spec

## Overview

Add a "Search for Book" option to the FAB menu, allowing users to find and add books by title/author when they don't have the ISBN barcode available.

---

## Product Requirements

### User Story

_"As a user, when I hear about a book I want to read but don't have it physically, I want to search for it by title and add it to my shelf so I can remember to read it later."_

### User Flow

1. User taps FAB → selects "Search for Book"
2. Search view opens with:
    - Title field (required)
    - Author field (optional)
    - Search button
3. User enters "Project Hail Mary" and taps Search
4. Results list shows matching books with covers and authors
5. User taps a result
6. Book preview shows with shelf selector
7. User confirms, book is added to selected shelf

### Use Cases

- Adding books to a "To Read" list from recommendations
- Adding books you saw reviewed online
- Building a wishlist of books to buy later
- Adding books you remember but don't own yet

---

## API Strategy

### Open Library Search API (FREE - RECOMMENDED)

**Search Endpoint:**

```
https://openlibrary.org/search.json?title={title}&author={author}
```

**Why Open Library:**

- ✅ Free, unlimited searches
- ✅ Returns title, author, cover, ISBN, publication year
- ✅ Good coverage of books
- ✅ Same source we use for ISBN lookup (consistency)

**Example Response:**

```json
{
  "numFound": 150,
  "docs": [
    {
      "title": "Project Hail Mary",
      "author_name": ["Andy Weir"],
      "first_publish_year": 2021,
      "isbn": ["9780593135204"],
      "cover_i": 10885300,
      "publisher": ["Ballantine Books"]
    }
  ]
}
```

### Google Books Alternative (FREE Backup)

```
https://www.googleapis.com/books/v1/volumes?q={query}
```

## Technical Implementation

### 1. Update ISBNService to Support Search

```swift
// Update ISBNService.swift to add search capability

struct BookSearchResult: Identifiable {
    let id: String  // Use ISBN or unique identifier
    let title: String
    let authors: [String]
    let isbn: String?
    let coverImageURL: String?
    let publishYear: Int?
    let publisher: String?
}

extension ISBNService {
    // MARK: - Search Books
    
    func searchBooks(title: String, author: String? = nil) async throws -> [BookSearchResult] {
        // Try Open Library first
        if let results = try? await searchOpenLibrary(title: title, author: author) {
            return results
        }
        
        // Fallback to Google Books
        return try await searchGoogleBooks(title: title, author: author)
    }
    
    private func searchOpenLibrary(title: String, author: String?) async throws -> [BookSearchResult] {
        var urlComponents = URLComponents(string: "https://openlibrary.org/search.json")!
        
        var queryItems = [URLQueryItem(name: "title", value: title)]
        if let author = author, !author.isEmpty {
            queryItems.append(URLQueryItem(name: "author", value: author))
        }
        queryItems.append(URLQueryItem(name: "limit", value: "20"))
        
        urlComponents.queryItems = queryItems
        
        guard let url = urlComponents.url else {
            throw ISBNError.invalidURL
        }
        
        let (data, response) = try await URLSession.shared.data(from: url)
        
        guard let httpResponse = response as? HTTPURLResponse,
              httpResponse.statusCode == 200 else {
            throw ISBNError.bookNotFound
        }
        
        let json = try JSONSerialization.jsonObject(with: data) as? [String: Any]
        guard let docs = json?["docs"] as? [[String: Any]] else {
            throw ISBNError.invalidResponse
        }
        
        return docs.compactMap { doc -> BookSearchResult? in
            guard let title = doc["title"] as? String else { return nil }
            
            let authors = doc["author_name"] as? [String] ?? []
            let isbn = (doc["isbn"] as? [String])?.first
            let publishYear = doc["first_publish_year"] as? Int
            let publisher = (doc["publisher"] as? [String])?.first
            
            var coverURL: String?
            if let coverID = doc["cover_i"] as? Int {
                coverURL = "https://covers.openlibrary.org/b/id/\(coverID)-M.jpg"
            }
            
            // Use ISBN as ID, or fall back to title+author combo
            let id = isbn ?? "\(title)-\(authors.first ?? "")"
            
            return BookSearchResult(
                id: id,
                title: title,
                authors: authors,
                isbn: isbn,
                coverImageURL: coverURL,
                publishYear: publishYear,
                publisher: publisher
            )
        }
    }
    
    private func searchGoogleBooks(title: String, author: String?) async throws -> [BookSearchResult] {
        var searchQuery = title
        if let author = author, !author.isEmpty {
            searchQuery += "+inauthor:\(author)"
        }
        
        let encodedQuery = searchQuery.addingPercentEncoding(withAllowedCharacters: .urlQueryAllowed) ?? searchQuery
        let urlString = "https://www.googleapis.com/books/v1/volumes?q=\(encodedQuery)&maxResults=20"
        
        guard let url = URL(string: urlString) else {
            throw ISBNError.invalidURL
        }
        
        let (data, response) = try await URLSession.shared.data(from: url)
        
        guard let httpResponse = response as? HTTPURLResponse,
              httpResponse.statusCode == 200 else {
            throw ISBNError.bookNotFound
        }
        
        let json = try JSONSerialization.jsonObject(with: data) as? [String: Any]
        guard let items = json?["items"] as? [[String: Any]] else {
            return []
        }
        
        return items.compactMap { item -> BookSearchResult? in
            guard let volumeInfo = item["volumeInfo"] as? [String: Any],
                  let title = volumeInfo["title"] as? String else {
                return nil
            }
            
            let authors = volumeInfo["authors"] as? [String] ?? []
            let publishYear = volumeInfo["publishedDate"] as? String
            let publisher = volumeInfo["publisher"] as? String
            
            let isbn = (volumeInfo["industryIdentifiers"] as? [[String: Any]])?
                .first(where: { ($0["type"] as? String)?.contains("ISBN") == true })?["identifier"] as? String
            
            var coverURL: String?
            if let imageLinks = volumeInfo["imageLinks"] as? [String: String] {
                coverURL = imageLinks["thumbnail"] ?? imageLinks["smallThumbnail"]
            }
            
            // Extract year from date string like "2021-05-04"
            let year = publishYear?.prefix(4).flatMap { Int($0) }
            
            let id = isbn ?? item["id"] as? String ?? title
            
            return BookSearchResult(
                id: id,
                title: title,
                authors: authors,
                isbn: isbn,
                coverImageURL: coverURL,
                publishYear: year,
                publisher: publisher
            )
        }
    }
}
```

```swift
import SwiftUI

struct BookSearchView: View {
    let defaultShelfId: UUID?
    let onBookAdded: () async -> Void

    @State private var titleQuery = ""
    @State private var authorQuery = ""
    @State private var searchResults: [BookSearchResult] = []
    @State private var isSearching = false
    @State private var hasSearched = false
    @State private var errorMessage: String?
    @State private var showError = false
    @State private var selectedBook: BookSearchResult?
    @State private var showBookPreview = false
    @Environment(\.dismiss) private var dismiss
    
    var body: some View {
        NavigationStack {
            VStack(spacing: 0) {
                // Search form
                Form {
                    Section {
                        TextField("Book Title", text: $titleQuery)
                            .textInputAutocapitalization(.words)
                            .submitLabel(.search)
                            .onSubmit {
                                performSearch()
                            }
                        
                        TextField("Author (optional)", text: $authorQuery)
                            .textInputAutocapitalization(.words)
                            .submitLabel(.search)
                            .onSubmit {
                                performSearch()
                            }
                    } header: {
                        Text("Search for a book")
                    } footer: {
                        Text("Enter at least a book title to search")
                    }
                    
                    Section {
                        Button {
                            performSearch()
                        } label: {
                            HStack {
                                Spacer()
                                if isSearching {
                                    ProgressView()
                                        .padding(.trailing, 8)
                                }
                                Text(isSearching ? "Searching..." : "Search")
                                    .fontWeight(.semibold)
                                Spacer()
                            }
                        }
                        .disabled(titleQuery.isEmpty || isSearching)
                    }
                }
                .frame(height: 250)
                
                Divider()
                
                // Results list
                if isSearching {
                    ProgressView("Searching...")
                        .frame(maxWidth: .infinity, maxHeight: .infinity)
                } else if hasSearched && searchResults.isEmpty {
                    ContentUnavailableView(
                        "No Results",
                        systemImage: "book.closed",
                        description: Text("Try a different search term")
                    )
                } else if !searchResults.isEmpty {
                    List {
                        Section {
                            ForEach(searchResults) { result in
                                BookSearchResultRow(result: result)
                                    .contentShape(Rectangle())
                                    .onTapGesture {
                                        selectedBook = result
                                        showBookPreview = true
                                    }
                            }
                        } header: {
                            Text("\(searchResults.count) results")
                        }
                    }
                    .listStyle(.plain)
                } else {
                    ContentUnavailableView(
                        "Search for Books",
                        systemImage: "magnifyingglass",
                        description: Text("Enter a book title to get started")
                    )
                }
            }
            .navigationTitle("Search Books")
            .navigationBarTitleDisplayMode(.inline)
            .toolbar {
                ToolbarItem(placement: .cancellationAction) {
                    Button("Cancel") {
                        dismiss()
                    }
                }
            }
            .sheet(isPresented: $showBookPreview) {
                if let book = selectedBook {
                    SearchBookPreviewView(
                        searchResult: book,
                        defaultShelfId: defaultShelfId,
                        onBookAdded: {
                            showBookPreview = false
                            dismiss()
                            await onBookAdded()
                        },
                        onCancel: {
                            showBookPreview = false
                            selectedBook = nil
                        }
                    )
                }
            }
            .alert("Error", isPresented: $showError) {
                Button("OK", role: .cancel) { }
            } message: {
                Text(errorMessage ?? "An error occurred")
            }
        }
    }
    
    private func performSearch() {
        guard !titleQuery.isEmpty else { return }
        
        isSearching = true
        hasSearched = true
        searchResults = []
        
        Task {
            do {
                let results = try await ISBNService.shared.searchBooks(
                    title: titleQuery,
                    author: authorQuery.isEmpty ? nil : authorQuery
                )
                
                await MainActor.run {
                    searchResults = results
                    isSearching = false
                }
            } catch {
                await MainActor.run {
                    errorMessage = error.localizedDescription
                    showError = true
                    isSearching = false
                }
            }
        }
    }
}

                                    .font(.caption)
```

```swift
                            }
                        }
                        
                        if let isbn = searchResult.isbn {
                            Text("ISBN: \(isbn)")
                                .font(.caption)
                                .foregroundStyle(.secondary)
                        }
                    }
                }
                
                Section {
                    Picker("Shelf", selection: $selectedShelfId) {
                        Text("Select a shelf").tag(nil as UUID?)
                        ForEach(shelves) { shelf in
                            Text(shelf.name).tag(shelf.id as UUID?)
                        }
                    }
                }
            }
            .navigationTitle("Add Book")
            .navigationBarTitleDisplayMode(.inline)
            .toolbar {
                ToolbarItem(placement: .cancellationAction) {
                    Button("Cancel") {
                        onCancel()
                    }
                }
                
                ToolbarItem(placement: .confirmationAction) {
                    Button("Add") {
                        saveBook()
                    }
                    .disabled(selectedShelfId == nil || isSaving)
                }
            }
            .alert("Error", isPresented: $showError) {
                Button("OK", role: .cancel) { }
            } message: {
                Text(errorMessage ?? "An error occurred")
            }
            .task {
                await loadShelves()
                await loadCover()
            }
        }
    }
    
    private func loadShelves() async {
        do {
            shelves = try await supabase.fetchShelves()
            if let defaultShelfId = defaultShelfId {
                selectedShelfId = defaultShelfId
            }
        } catch {
            errorMessage = error.localizedDescription
            showError = true
        }
    }
    
    private func loadCover() async {
        guard let urlString = searchResult.coverImageURL,
              let url = URL(string: urlString) else {
            return
        }
        
        do {
            let (data, _) = try await URLSession.shared.data(from: url)
            if let image = UIImage(data: data) {
                await MainActor.run {
                    self.coverImage = image
                }
            }
        } catch {
            print("Error loading cover: \(error)")
        }
    }
    
    private func saveBook() {
        guard let shelfId = selectedShelfId else { return }
        
        isSaving = true
        
        Task {
            do {
                let author = searchResult.authors.isEmpty ? nil : searchResult.authors.joined(separator: ", ")
                
                // Upload cover if available
                var coverUrl: String?
                if let coverImage = coverImage {
                    let tempBookId = UUID()
                    coverUrl = try? await CoverImageService.shared.uploadCoverImage(coverImage, for: tempBookId)
                }
                
                // Create book
                _ = try await supabase.createBook(
                    title: searchResult.title,
                    author: author,
                    shelfId: shelfId,
                    coverUrl: coverUrl
                )
                
                await onBookAdded()
            } catch {
                await MainActor.run {
                    errorMessage = error.localizedDescription
                    showError = true
                    isSaving = false
                }
            }
        }
    }
}
```

### Search Flow

1. **Empty State**: "Search for Books" with magnifying glass
2. **Typing**: Real-time validation (title required)
3. **Searching**: Progress indicator + "Searching..."
4. **Results**: List with covers, authors, year, publisher
5. **Tap Result**: Preview with shelf selector
6. **Confirm**: Book added, returns to shelf

### Search Tips

- Partial titles work (e.g., "Project Hail" finds "Project Hail Mary")
- Author optional but helps narrow results
- Shows up to 20 results
- Cover images load asynchronously

---

## Edge Cases

### Handled

- ✅ No search results → "No Results" message
- ✅ Network error → Error alert with retry
- ✅ Missing cover images → Placeholder icon
- ✅ Books without ISBN → Uses title+author as ID
- ✅ Long titles/author names → Truncated with ellipsis
- ✅ Empty author field → Only searches by title

### Future Enhancements

- Pagination for >20 results
- Search history / recent searches
- Fuzzy matching for typos

- Sort options (relevance, date, title)

# Book Notes Feature - PRD & Technical Spec

## Overview

Add a simple notes field to each book where users can write thoughts, quotes, or reminders. Notes auto-save as you type and display prominently on the book detail screen.

---

## Product Requirements

### User Story

_"As a user, I want to jot down thoughts about each book - like quotes I loved, key takeaways, or why I want to read it - so I can remember important details later."_

### Use Cases

- **Book recommendations**: "Sarah recommended this at book club"
- **Reading notes**: "The chapter on quantum mechanics was mind-blowing"
- **Quotes**: "Man's search for meaning..."
- **Why to read**: "Covers Byzantine history, which I need for the novel"
- **Status tracking**: "On hold until sequel releases"
- **Personal thoughts**: "Reminds me of my trip to Sicily"

### Behavior

- **Single text field per book** (not threaded comments)
- **Plain text** with newlines/paragraphs
- **Auto-save** as you type (debounced)
- **Tap to edit** on detail view
- **Optional** - books can have empty notes
- **No formatting** - just plain text (keeps it simple)

---


```swift
// Update createBook to accept notes
func createBook(
    title: String, 
    author: String?, 
    shelfId: UUID, 
    coverUrl: String? = nil,
    notes: String? = nil  // NEW
) async throws -> Book {
    guard let userId = getCurrentUserId() else {
        throw SupabaseError.notAuthenticated
    }
    
    let newBook = BookInsert(
        title: title,
        author: author,
        shelfId: shelfId,
        userId: userId,
        coverUrl: coverUrl,
        notes: notes  // NEW
    )
    
    let response: Book = try await client
        .from("books")
        .insert(newBook)
        .select()
        .single()
        .execute()
        .value
    
    return response
}

// Update updateBook to accept notes
func updateBook(
    id: UUID, 
    title: String, 
    author: String?, 
    shelfId: UUID, 
    coverUrl: String? = nil,
    notes: String? = nil  // NEW
) async throws {
    let update = BookUpdate(
        title: title,
        author: author,
        shelfId: shelfId,
        coverUrl: coverUrl,
        notes: notes  // NEW
    )
    
    try await client
        .from("books")
        .update(update)
        .eq("id", value: id.uuidString)
        .execute()
}

// New method to update only notes (for auto-save)
func updateBookNotes(id: UUID, notes: String?) async throws {
    struct NotesUpdate: Encodable {
        let notes: String?
    }
    
    let update = NotesUpdate(notes: notes)
    
    try await client
        .from("books")
        .update(update)
        .eq("id", value: id.uuidString)
        .execute()
}
```

## User Experience

### Auto-Save Behavior

1. User taps to edit notes
2. TextEditor appears with blue border
3. User types...
4. After 1 second of no typing → auto-save
5. User continues typing → another 1 second delay
6. User taps "Done" → final save and exit editing mode

### Save Strategy

- **Debounced auto-save**: 1 second delay after last keystroke
- **Final save on "Done"**: Ensures last changes saved
- **Silent save**: No success message (don't interrupt typing)
- **Error handling**: Log errors but don't block user

---

## Technical Details

### Debouncing Strategy

```swift
@State private var saveTask: Task<Void, Never>?

.onChange(of: editableNotes) { _, newValue in
    // Cancel previous save task
    saveTask?.cancel()
    
    // Create new save task with 1 second delay
    saveTask = Task {
        try? await Task.sleep(for: .seconds(1))
        if !Task.isCancelled {
            await saveNotes(newValue)
        }
    }
}
```

**Why this works:**

- Cancels previous save if user keeps typing
- Only saves after 1 second of inactivity
- Task-based for proper cancellation
- Final save on "Done" ensures data integrity

### Storage

- Plain text in PostgreSQL `TEXT` column
- Unlimited length (practically speaking)
- Indexed for future search feature
- NULL when empty (saves space)

---

## Edge Cases Handled

✅ **Empty notes** → Stored as NULL, empty state shows  
✅ **Very long notes** → TextEditor scrolls, no limit  
✅ **Network error during save** → Silent failure, retry on next edit  
✅ **User exits while typing** → `onDisappear` cancels pending save  
✅ **Whitespace-only notes** → Trimmed and saved as NULL  
✅ **Newlines and paragraphs** → Preserved correctly  
✅ **Special characters** → Supported (quotes, emojis, etc.)

## FAQ

**Q: Why not use Action Text like the Rails app had?**  
A: Action Text is Rails-specific. For our use case, a simple TEXT column is perfect - no HTML, no attachments, just plain notes.

**Q: What if someone writes a novel-length note?**  
A: PostgreSQL TEXT can handle ~1GB. TextEditor scrolls. In practice, notes are usually a few sentences.

**Q: Can I format text (bold, italic)?**  
A: Not in v1. Plain text keeps it simple. Could add Markdown rendering in v2.

**Q: Will auto-save drain battery?**  
A: No - saves are debounced (1 second), lightweight, and only on changes. Negligible impact.

**Q: What if my network is slow?**  
A: Auto-save fails silently. Next edit will retry. Final save on "Done" ensures data persists.

**Q: Can I search my notes?**  
A: Not yet, but we've added a database index for future search implementation.

**Q: Do notes sync across devices?**  
A: Yes! Stored in Supabase, so any device logged in as you sees the same notes.
